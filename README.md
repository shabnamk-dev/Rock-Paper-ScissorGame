# ROCK PAPER SCISSORS GAME

A simple yet interactive Rock Paper Scissor game built using **HTML, CSS, JAVASCRIPT**.
This project was originally created while following a tutorial and later enhanced with custom features and UI improvements.

_____________________

##FEATURES
- Play Rock, Paper, Scissors against the computer.
- Real-time score tracking
- Tie counter added as a custom feature.
- clean and responsive UI design.
- Custom background styling
- Hover Effects for better interactivity
- smooth and simple gameplay logic.

##Tech Stack
-HTML
-CSS
-JAVASCRIPT

##What I learned 
- DOM manipulation in JavaScript
- Handling user interaction with event listener
- implementing game logic
- updating UI dynamically
- customizing and improving a base project
